Pure Lock 1.2.10:

Pure Lock 1.2.10 brings the major changes and fixes that are listed below. All users are recommended to update as soon as possible. The update is available for all Pure Lock users regardless the Android/One UI versions.

  • Better compliance with new Google Play's policies. However, this also prevents Pure Lock server from remotely adding new modules to the list. A full Pure Lock update is required. There's currently no workaround since this is explicitly prohibited. The new policies prevent bad apps from abusing users' privacy, but they also affect good apps including Pure Lock.
  • Fix the issue with Dynamic wallpaper on One UI 1.
  • Fix the compatibility issue with LockStar 1 for Oreo and One UI 1 users.
  • Fix the compatibility issue with LockStar 3 for One UI 4 users.
  • Pure Lock now uses Lato fonts for content text. Lato with better letter width and spacing allows more content to be displayed on the same screen area with the same readability. However, if you don't like it, or there are issues with the text, you can switch to system fonts by disabling Use custom fonts option under General settings section in Pure Lock's Settings screen. This also applies to Pure Lock website, which you're currently looking at.
  • Pro users can pin up to 6 modules to the top of the list, as long as they're not dependencies (Good Guardians, Good Guardians Agent and Good Lock). To unpin all the modules at once, select the last option under Pro settings section in Pure Lock's Settings screen.
  • An important change to Auto check for updates: Starting with Pure Lock 1.2.10, auto check for updates is handled by Pure Lock server. Pro users will receive a notification when there's at least one available update.

This release is expected to be the final release for Oreo and One UI 1 users. Support for One UI 2 has been extended and will end on December 31st, 2022.

However, HomeUp only works on A40+, S and Note devices running Android 10 and One UI 2 with the latest security patch and One UI Home from Galaxy Store. If your device is not supported, HomeUp will crash and you'll see something like the screenshot below:


In that case, please do the following steps:
